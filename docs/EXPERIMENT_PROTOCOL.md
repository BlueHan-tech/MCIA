# MCIA 主实验协议

版本：2026-09-10（重定义版，同日修订：T1 计数语义统一、双主任务、连续点规则锁定）

本文是当前主实验的唯一设计规范。它定义后续开发、确认和报告的边界；不追溯性地改变任何历史 run 的含义。`config.yaml` 与代码是当前实现快照，若与本文不一致，必须明确记录并在启动确认实验前解决，不得静默以任一方覆盖另一方。

## 1. 研究问题与结论边界

主问题是：在相同的截肢者、repetition 划分、质量掩码和单一下游模型下，MCIA 补全是否改善下游性能？本协议定义**两个并列主任务**，重要性相等、各自拥有独立主终点：

1. **连续关节角度估计**（Key10，连续角度主终点，§7.1）；
2. **48 类手势识别**（GestureTCN，手势主终点，§7.2）。

宣称"MCIA 补全改善下游性能"的整体结论，要求两个主任务同时满足各自 §7 判据；仅其中一项满足时，结论必须按任务分别陈述，不得外推到另一任务。

| 组别 | 下游输入 | 目的 |
| --- | --- | --- |
| A（raw） | 原始预处理后 DB3 EMG，不进行补全替换 | 临床记录的未校正参照 |
| B（healthy prior） | 健康 DB2 先验 MCIA 在 DB3 质量掩码处补全的 EMG | 健康人到截肢者的零样本迁移 |
| C（amputee-donor prior） | 健康 DB2 先验经清洁截肢者供体无标签适配后，在同一 DB3 质量掩码处补全的 EMG | 截肢者域适配的增益 |

组 C 不是已退役的“目标受试者原始 EMG 作真值”的个体微调。它只使用**其他**清洁截肢者的 EMG 作为无标签供体，目标受试者的 glove、验证或测试数据绝不进入 C 的适配。SGMD-AAE 和 CP-WOPT 的任务适配比较属于补充方法学比较，不替代 A/B/C 的临床主结论。

EMG 重建误差与供体上的人工遮挡重建为辅助证据，不能单独宣称方法有效。

## 2. 受试者角色与数据隔离

### 2.1 清洁截肢者供体池

- 供体固定为 DB3 `S02/S04/S08/S11`。
- 入选依据是冻结的 WC-BQD v0.1 质量审计中，这四名被试在当前 E1--E3 数据上没有检测到需补全区域；这只表示未检测到 T1/T2/T3 定义的故障，不等价于绝对无噪声或临床金标准。
- 供体仅提供 EMG；不使用 glove、动作标签或目标受试者信息来训练 C。
- C 的供体适配只允许使用供体 E1/E2 的 repetitions `1/3/4`；供体 repetition 6 只可用于选择 C checkpoint，供体 repetitions `2/5` 不参与任何选择或适配。

### 2.2 目标受试者与阶段

| 阶段 | 目标受试者 | 用途 |
| --- | --- | --- |
| 开发 | S05、S06 | 只可使用 repetitions `1/3/4` 和 `6` 比较候选 C 设置、确定训练预算与 checkpoint 规则。历史上已查看的 S05/S06 test 结果永久标为已使用，不能再作为未见测试证据。 |
| 确认 | S03、S07、S09 | 方案冻结后的独立目标被试。训练 repetitions `1/3/4`，验证 repetition `6` 只用于既定 early stopping 和仿射校准，测试 repetitions `2/5` 只用于一次性报告。 |

选择供体和确认目标不依据其连续角度或手势测试表现。确认集的 E1+E2 paired EMG/glove 可用性必须在启动前检查；任何缺失必须完整报告，不得以结果为由替换被试。

被试角色三分（供体/开发/确认）**同时适用于两个主任务**：手势任务同样使用 DB3 的 9 名被试（S02–S11），角色划分与 §2.1/§2.2 完全一致。

## 3. 固定数据与预处理

- 连续角度任务：DB3 E1+E2，exercise 独立滑窗，禁止窗口跨 exercise 或跨 repetition 划分。
- 原始 sEMG 为 2 kHz；统一经过带通、50 Hz 陷波、整流、10 点包络、降采样，得到 200 Hz 表示。
- 窗口固定为 `256 x 12`，stride `128`；每窗口覆盖 1.28 s。
- EMG 采用仅由该目标被试训练 repetitions `1/3/4` 拟合的 μ-law + Q5/Q99 归一化，裁剪至 `[0,1]`。
- Key10 目标固定使用原始 glove 的零基索引 `[1,2,4,5,7,8,11,12,15,16]`；标签是训练统计归一化后的 glove 值，不能称为角度“度”。
- repetition 划分固定：训练 `1/3/4`，验证 `6`，测试 `2/5`；随机种子固定为 42。
- 手势任务数据：DB3 E1+E2+E3，动作 `1–48`（排除 49），窗口标签纯度过滤 `min_label_ratio 0.80`、`min_repetition_ratio 0.80`（实现以 `config.yaml` 的 `exp4_gesture` 与 `scripts/05` 为准）；EMG 预处理、归一化与掩码与角度任务完全一致。

## 4. 缺失定义与补全交付

- 质量掩码固定为 `hard_zero_train_1_3_4 OR WC-BQD v0.1`；检测器基线仅由目标被试、对应 exercise 的训练 repetitions `1/3/4` 活动段拟合。
- T1 平台计数语义已统一为**相同采样点数**（2026-09-10 修复差一错误：此前实现计的是相等对数、阈值实际多要一个采样点；修复后 healthy/healthy_ext/db3 三阶段验收已全部刷新，所有判定与数字不变）。WC-BQD 的全部常量、源代码 hash 与边界单元测试必须在确认测试前保存。
- B/C 的交付规则固定为：模型预测裁剪至 `[0,1]`，执行 patch 边界淡化，再把所有观测值逐点复制回输出。A 不使用任何模型替换。
- A/B/C 在同一受试者、同一窗口上使用完全相同的质量掩码。不得按方法重新检测异常、改变掩码、或用预测选择补全位置。

## 5. C：截肢者供体域适配

1. 从已锁定的健康 DB2 MCIA checkpoint 开始。
2. 仅以供体池的可观测 EMG 进行 masked reconstruction 自监督适配：人为遮挡的区域以原始供体观测 EMG 为重建目标，损失仅在人工遮挡位置计算。
3. 人工掩码采用项目冻结的 patch 对齐 ScenarioMix；不得用确认目标的验证/测试掩码或 glove 调整掩码分布。
4. 适配后模型对每位目标被试独立推理，但权重相同；禁止以目标被试原始缺失位置的不可观测值监督模型。
5. 学习率、可训练层、epoch 上限、early-stopping patience 和 C checkpoint 选择指标必须在开发阶段仅用 S05/S06 的训练/验证 repetitions 选定，并写入确认 run 的 `00_config`。参数冻结前，C 只能称为开发候选，不能启动确认测试。

这种设计检验的是“健康先验经无标签截肢者供体域适配”是否有增益；它不能证明针对单个永久死通道存在该受试者特异的真实波形恢复。

## 6. 下游模型与训练公平性

- 角度任务：A/B/C 均从零训练同一非因果 same-padding Key10 KinematicTCN：hidden dimension 64、6 layers、kernel size 3、dropout 0.1。
- 每组使用同一训练/验证/测试窗口、同一 seed、batch size 64、AdamW、learning rate 0.001、最多 100 epochs、patience 20、scheduler patience 5、factor 0.5。
- 角度 TCN checkpoint 只按 validation loss 选择。连续输出统一采用 triangular overlap-add、6 Hz Butterworth 和仅由 validation prediction/target 拟合的逐通道 affine 校准。
- 手势任务：A/B/C 均从零训练同一 GestureTCN（与角度任务同构的 TCN backbone：hidden 64、6 layers、kernel 3、dropout 0.1，加 48 类线性分类头）；训练窗口、seed、优化器与预算规则与角度任务一致；checkpoint 与早停按**验证 macro-F1** 选择。
- 每个方法/组的下游模型必须重新初始化；不得把 A 的权重迁移给 B/C，也不得修改模型结构来补偿某一补全方法。

## 7. 终点、聚合与成功判据

两个主任务各有一个锁定主终点，判据独立评估；整体结论按 §1 的双任务规则陈述。确认样本量为 3，不报告或解释显著性 p 值；报告每名被试的配对差、均值、标准差和有效样本数。

### 7.1 主终点一：连续角度估计

确认集 S03/S07/S09 的连续输出 `global Key10 RMSE`。先在每名被试的全部有效连续点与 10 个通道上计算 RMSE，再对三名被试等权平均。

**有效连续点定义（锁定）**：连续输出点必须位于同一 exercise 内的时间连续片段上，且每个时间点至少被两个重叠窗口覆盖；逐点重叠覆盖数与重叠区预测一致性一并落盘（实现以 `utils/kinematic_output_postprocess` 与 `scripts/04` 的连续输出规则为准，跨 exercise 边界不拼接）。

主要比较为配对的 `C - A`。C 被判为角度主终点改善，当且仅当：

1. 三名确认被试的等权平均 `RMSE_C - RMSE_A < 0`；且
2. 至少 2/3 名确认被试的 `RMSE_C - RMSE_A < 0`。

`C - B` 是预先指定的机制性次要比较，`B - A` 是健康先验次要比较。任何失败、缺失或无有效动态轨迹的被试均保留在 global 报告中并说明原因。

### 7.2 主终点二：手势识别

确认集 S03/S07/S09 的测试窗口 `macro-F1`（48 类）。先按被试计算，再对三名被试等权平均。

主要比较为配对的 `C - A`。C 被判为手势主终点改善，当且仅当：

1. 三名确认被试的等权平均 `F1_C - F1_A > 0`；且
2. 至少 2/3 名确认被试的 `F1_C - F1_A > 0`。

次要手势终点：trial-majority accuracy、window accuracy、balanced accuracy 与混淆矩阵；`C - B`、`B - A` 次要比较同 7.1。任何被试缺失或类别无效均保留并说明原因。

### 7.3 次要角度终点

在与主终点相同的连续输出口径下，报告 global/MCP/PIP 的 RMSE、MAE、Pearson、R²；窗口级指标和 dynamic subset 仅作诊断，不能替换主终点。

### 7.4 补全辅助终点

对存在已知真值的人工遮挡验证或文献 baseline 比较，仅在缺失区域计算：NRMSE（峰值固定 1）、PSNR（峰值固定 1）、RME 和 masked Pearson。观测值复制回填后不得计入误差。不同表示、掩码或归一化的历史指标不得直接排名。

### 7.5 补全方法学前提判据（必须结果）

在健康 DB2 受控掩码补全上，MCIA 必须优于两个文献 baseline。这是论文方法贡献的必要结果；设置如下：

- 数据与掩码：DB2 留出被试 `S33–S40`（先验从未用于拟合或选择）；受控掩码为冻结的 ScenarioMix（固定种子，与预训练同族，需在报告中披露这一点）。
- 口径：仅在人工掩码区域按 §7.4 评估；主判据为被试等权 `masked NRMSE`（峰值 1）均值，PSNR/RME/masked Pearson 同报。
- 公平性：SGMD-AAE 以与 MCIA 相同的 DB2 训练被试与 ScenarioMix 预训练后零样本推理；CP-WOPT 按被试、按留出分区的观测 EMG 拟合并标注 split-transductive；**所有方法统一施加相同交付后处理**（裁剪至 `[0,1]`、patch 边界淡化、观测回填）。
- 成功判据：MCIA 的被试等权 masked NRMSE 均值同时低于 SGMD-AAE 与 CP-WOPT，且对每个 baseline 至少 `4/8` 名被试逐被试更优。
- 防选择纪律：任何开发迭代只允许使用验证被试 `S29–S32`；`S33–S40` 上的每次评估必须完整披露次数与用途，重复评估不得声称为一次性未见测试。
- 失败语义：本判据未满足时，不得宣称 MCIA 为更优的 EMG 补全方法；A/B/C 下游结论在逻辑上独立于本判据，仍可按本协议报告，但必须与该失败结果并置呈现，不得隐瞒或淡化。

## 8. 文献 baseline 的任务内比较

SGMD-AAE 与 CP-WOPT 使用相同的 DB3 200 Hz 包络、相同质量掩码和同一 Key10 TCN，并与 MCIA 同表报告下游终点。

- DB3 真实质量掩码区域没有干净真值，不得在该表计算或报告任何补全质量指标（对被录制坏信号算距离会奖励全零预测）；补全质量对比仅在有人工遮挡真值的基准上进行（§7.5 健康基准、供体人工遮挡验证）。
- SGMD-AAE 的 `256 x 12`、200 Hz 版本是任务适配，不是其原始论文的 `240 x 12`、2 kHz 数值复现；核心网络与损失保持文献实现，必须如此标注。
- CP-WOPT 在每个未标注 DB3 split 的观测 EMG 上拟合，因此是 split-transductive 方法；不得把它表述为与 MCIA 相同的归纳式部署模型。
- 这两种 baseline 的排序不改变 A/B/C 的主终点或 C 的 checkpoint 选择。
- 文献 baseline 当前实现仅覆盖连续角度任务，不参与手势主终点的比较。

## 9. 冻结、执行与报告

1. 在任何确认测试前，保存本协议版本、代码 hash、`config.yaml` snapshot、WC-BQD 常量/边界测试、C 训练设置、供体/目标名单及排除规则。
2. 开发只使用 S05/S06 的训练/验证 repetitions；一旦选定 C 设置，禁止再以确认集的任何指标选择参数、图像、被试或指标。
3. 确认 run 按顺序保存每名被试的掩码、补全 EMG、TCN checkpoint、窗口预测、连续预测、metrics、日志和图像。执行规则以 [REPRODUCIBILITY.md](rules/REPRODUCIBILITY.md) 为准，绘图验证以 [PLOTTING.md](rules/PLOTTING.md) 为准。
4. 已查看的历史 S05/S06 测试结果只能作为 legacy 探索记录；不得与确认集混合后声称为未见测试。
5. 只有确认 run 完成且 §7.1 与 §7.2 判据分别满足时，才可按 §1 的双任务规则宣称"MCIA 补全改善下游性能"；任一任务未满足时，对该任务如实报告无改善或证据不足，不得外推。
6. §7.5 前提判据的一次性冻结报告（无论通过与否）应在确认 run 启动前完成并披露；论文的方法优越性主张以该报告为准。
