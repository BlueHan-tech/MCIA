## 待讨论

### 手势窗口与响应时延

- 当前：协议使用 1.28 秒窗口、0.64 秒步长。
- 已决定：手势窗口时长改为 300 ms；按用户要求，等用户明确要求修改项目时再实施。
- 待讨论：相邻窗口是否重叠 250 ms（即步长 50 ms）。DSRANet 报告采用 300 ms 外层窗口、250 ms 重叠；每个窗口内部再以 64 ms Hamming 窗、16 ms 帧步长计算 STFT，形成 `12 × 65 × 19` 表示。外层 50 ms 步长与 STFT 内部 16 ms 帧步长不可混为一谈。
- 启发与边界：250 ms 重叠意味着每 50 ms 更新一次分类，但相邻样本高度重叠；沿用时须先按 repetition 划分，再生成窗口。论文同时改变了 STFT 表示和网络结构，不能把其 DB3 准确率归因于窗口重叠本身。详见 [DSRANet](https://doi.org/10.1016/j.bspc.2025.108845) 及[对应方法专利](https://patents.google.com/patent/CN120256824A/en)。

### Butterworth 低通滤波

- 当前：协议列出带通、50 Hz 陷波、整流、10 点包络和降采样；未定义在原始肌电或 STFT 前额外增加独立 Butterworth 低通。角度预测输出端的 6 Hz Butterworth 是另一处理步骤。
- 待讨论：是否增加低通、加在原始肌电还是整流/包络之后、是否服务于降采样抗混叠，以及截止频率、阶数和因果实现。
- 证据边界：DSRANet 的已核对方法段给出 STFT 参数，但没有明确说明 Butterworth 低通；不能据此把低通视为该高精度结果的必要条件。

### 采样率与补全输入

- 当前：原始 2 kHz 肌电经预处理形成 200 Hz 包络表示。
- 理由：高采样率可能保留更多肌电细节；当前整体效果不理想，值得检查降采样是否损失了有用信息。
- 方向：讨论是否在 2 kHz 上进行补全及后续解码，并明确时延与计算代价。

### 截肢者肌电的质量判定

- 想法：区分相对正常与异常肌电；正常段用于有参照地评估补全，异常段在补全时按缺失处理。
- 待讨论：如何定义判定规则，以及“正常”是否足以作为可靠真值。当前尚未形成可采用的规则。
