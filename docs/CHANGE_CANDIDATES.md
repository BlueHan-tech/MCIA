## 已决定，待实施

### 全链路统一窗口设置

- 已决定：生成式补全、手势识别和连续关节角度估计共用 300 ms 窗口、250 ms 重叠、50 ms 步长；按用户要求，等用户明确要求修改项目时再实施。
- 样本数按采样率换算：2 kHz 下为 600 点窗口、100 点步长；200 Hz 下为 60 点窗口、10 点步长。统一的是时间范围和更新间隔，不是所有模型都必须使用同一采样率或输入表示。
- 启发与边界：DSRANet 在 DB3 手势识别中报告 300 ms 外层窗口、250 ms 重叠；窗口内 STFT 另用 64 ms Hamming 窗、16 ms 帧步长。该论文支持手势链路上的可行性，但不能证明同一设置对补全和连续角度估计最优，也不能把精度差异归因于窗口重叠。详见 [DSRANet](https://doi.org/10.1016/j.bspc.2025.108845) 及[对应方法专利](https://patents.google.com/patent/CN120256824A/en)。

### 全链路采样率

- 已决定：补全输入/输出为 2 kHz 原始肌电；手势识别使用补全后的 2 kHz 信号；角度估计将同一补全结果整流、平滑并降采样为 200 Hz 包络。目标窗口分别为 2 kHz 下 600 点/步长 100 点，200 Hz 下 60 点/步长 10 点。
- 依据与边界：DB3 的 DSRANet 以 2 kHz 肌电生成 STFT 表示用于手势识别；DB2 角度估计论文将 2 kHz 肌电整流、均值滤波并降采样十倍至 200 Hz。文献支持分支选择，但不证明 2 kHz 原始波形补全会优于 200 Hz 包络补全。[DSRANet](https://doi.org/10.1016/j.bspc.2025.108845)；[DB2 角度估计](https://doi.org/10.1002/aisy.202500590)。
- 风险：当前补全模型处理 200 Hz 包络；改为补全 2 kHz 原始波形会改变重建目标并增加计算量。50 ms 步长要求持续处理每秒 20 个窗口；需在开发数据上验证补全质量、两个下游任务及吞吐。代码尚未修改，按用户此前要求等明确实施指令。

### 恒定通道与归一化数值保护

- 已决定（D-016）：下游训练输入完全恒定的通道，中心化后标准化输出固定为零，不用极小标准差放大数值误差；这是数值保护，不新增质量筛选，不把缺失零值作为补全真值。

- 状态：只记录已获接受的推荐；代码未改，数值和精度未验证。

### 补全输出与交付基本原则

- 已决定（D-017）：采用允许正负值的线性输出头，移除旧 Softplus 非负限制及 `[0,1]` 裁剪，不额外设置固定硬幅值上下限；不以 `tanh` 或其他固定有界激活替代。Z-score 波形不受 `[0,1]` 或 `[-1,1]` 范围约束。
- 仅替换冻结质量掩码指定的缺失位置，正常观测点保持为前端滤波后的记录值；不因补全或接缝平滑改写观测区。反归一化继续按 D-016 使用保存的同一套统计量。
- 同一组、同一被试记录形成一份统一的 2 kHz 补全交付波形，再分别生成角度包络和手势谱；不为两个任务分别生成不同补全结果。B/C 各自补全，使用相同交付规则，不表示两组交付数值相同。
- 状态：仅更新文档，代码待实施，效果待验证。补全窗口拼接及首版后处理按 D-018。

### 补全窗口中心拼接＋局部短过渡

### 分区内滤波与静息预热

- 已决定（D-019/D-034）。前端带通和角度 5 Hz 低通均在分区内连续处理，真实静息预热的参考长度分别为 60 ms（120 点）和 250 ms（500 点），均从首个保留窗的起点往前计。优先处理同一连续段内可用的真实静息并传递滤波状态。静息不足时使用已有部分，无可用静息时用各滤波阶段输入的首样本初始化至稳态。分区切换或记录中断时重置状态，保留首窗及原时间索引。见[实验协议 §3](EXPERIMENT_PROTOCOL.md#3-固定数据与预处理)。

### 回填波形损失与固定重建尺度

- 已决定（D-020）。主重建指标为固定 DB2 训练尺度的 masked RMSE。辅助指标为同尺度的 masked MAE 和 40 ms 局部 RMS 误差，适用于有已知真值的人工遮挡，详见[协议 §7.4](EXPERIMENT_PROTOCOL.md#74-补全辅助终点)。
- 已决定（D-038/D-040），待实施。B/C 共用首版补全损失，人工缺失区 Charbonnier 权重为 `1.0`，40 ms RMS 为 `0.2`，双尺度 STFT 对数幅度差为 `0.1`，接缝一阶差分为 `0.05`。辅助项以回填波形计算，首版关闭独立包络、NCC、旧幅值范围惩罚和额外辅助项。见[实验协议 §4](EXPERIMENT_PROTOCOL.md#4-缺失定义与补全交付)。

### 补全 patch 与训练人工遮挡

- 已决定（D-023）：每个 patch 为 40 点（20 ms），600 点窗口含 15 个 patch。S1/S2/S3 权重为 `0.20/0.40/0.40`，按原约束分别遮挡 `0/1/2` 条整窗电极，再从剩余电极中随机选 `4/4/3` 条做局部遮挡。每条被选电极独立放一个连续块，块长等概率取 `80/120/160 ms`，对应 `4/6/8` 个 patch，起点对齐 patch。
