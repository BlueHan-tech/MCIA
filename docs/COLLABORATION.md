- **D-009｜已决定，待用户启动实施｜2026-10-30**：生成式补全、手势识别和连续关节角度估计共用 300 ms 窗口、250 ms 重叠、50 ms 步长。此时序设置尚未验证精度、运行吞吐或端到端延迟。
- **D-010｜已决定，待用户启动实施｜2026-10-30**：补全输入/输出保留 2 kHz 原始肌电；手势识别使用补全后的 2 kHz 信号；角度估计从同一补全结果出发，经现有预处理得到 200 Hz 包络。窗口换算为 2 kHz 下 600/100 点、200 Hz 下 60/10 点。依据：DB3 DSRANet 使用 2 kHz 信号的 STFT 手势路线（[论文](https://doi.org/10.1016/j.bspc.2025.108845)）；DB2 关节角度研究将 2 kHz 肌电整流、均值滤波并降采样十倍至 200 Hz（[论文](https://doi.org/10.1002/aisy.202500590)）。这些论文支持任务分支的处理参考，不证明 2 kHz 生成式补全优于现有 200 Hz 包络补全；当前代码尚未更新，按用户此前要求待明确实施指令后执行。

- **D-011｜已决定，待用户启动实施｜2026-11-02**：补全前采用常规滤波与训练统计量逐通道 Z-score；链路为 `2 kHz 有符号肌电 → 常规滤波 → Z-score → 补全 → 同统计量反归一化 → 分支处理`。当前不增加小波、学习式去噪或复杂训练异常筛选，保留既有 DB3 质量掩码；不据此声称异常无影响。前端滤波按 D-014、分支路线按 D-012/D-013、统计范围及恒定通道原则按 D-015/D-016、输出及交付按 D-017/D-018，滤波边界及初始化按 D-019，补全损失与重建指标按 D-020。目的：统一新补全表示并控制改动范围。主链路尚未实施，效果未验证；见协议 §3、§4、§7.4 和[待改事项](CHANGE_CANDIDATES.md)。

- **D-012｜已决定，待用户启动实施｜2026-11-02**：角度分支采用补全后反归一化波形 → 全波整流 → 二阶单向 Butterworth 低通（5 Hz）→ 200 Hz、12 通道 → 独立的逐通道训练统计量 Z-score → 300 ms/50 ms Key10 KinematicTCN。用户在文献讨论后确认“那就决定为5hz”；解码器、标签、训练及输出后处理沿用协议。目的：确定角度输入包络及截止频率。只更新文档，主链路未改，效果及延迟未验证；见协议 §3 与[来源记录](#角度包络参数来源与确认边界2026-11-02d-012)。
